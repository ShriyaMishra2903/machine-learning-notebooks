# Unsupervised Learning

This folder contains notebooks related to unsupervised machine learning algorithms.

Unsupervised learning discovers hidden patterns and structures in unlabeled data.

## Topics Covered

* K-Means Clustering
* Hierarchical Clustering
* DBSCAN
* Principal Component Analysis (PCA)

## Learning Goals

* Perform clustering analysis
* Discover hidden data patterns
* Reduce dimensionality
* Visualize complex datasets
