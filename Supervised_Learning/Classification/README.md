# Classification

This folder contains notebooks related to classification algorithms.

Classification models are used to predict categorical outcomes based on input data.

## Topics Covered

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Support Vector Machine (SVM)
* Naive Bayes
* Decision Tree
* Random Forest

## Learning Goals

* Understand classification techniques
* Train classification models
* Evaluate model performance
* Compare different algorithms
